03

THE STANDARD ROUTE

用 KiwiVM 重装 Linux

以下流程以面板提供的系统镜像为例。实际菜单与可选版本请以控制面板显示为准。

  1. 登录控制面板

    在账号中进入 Services → My Services，找到目标 VPS，打开 KiwiVM Control Panel。

  2. 停止 VPS

    在 Main Controls 查看运行状态。如果显示 Running，点击 Stop 并等待停机，再进行重装。

  3. 选择系统

    进入 Install new OS，从当前列表中选择所需的 Linux 发行版和版本，例如 Ubuntu 或 Debian。

  4. 确认清除并安装

    确认已备份数据，勾选同意数据将被清除的选项，再点击 Reload 开始安装。

  5. 保存新的连接信息

    安装完成后，留意并妥善保存面板显示的 root 密码和 SSH 端口；连接时使用新的信息。

04

THE ADVANCED ROUTE

DD 与自定义系统

DD 将完整镜像写入磁盘，可用于有特殊需求的系统安装，但操作失误或使用不可信镜像可能造成数据丢失与安全风险。它需要 KVM 环境，也需要熟悉 SSH 和目标镜像的安装流程。

大致流程

先通过 KiwiVM 安装基础 Linux → 使用 SSH 连接 → 按可信镜像对应的流程写入磁盘 → 通过面板控制台观察安装 → 用新系统信息重新连接。

写盘时 SSH 连接可能中断。安装后应立即修改镜像的默认密码。若需要其他系统，也可以在面板核实 Mount ISO 选项及可用镜像；具体支持情况以面板为准。

05

AFTER INSTALLATION

重新连接与排查

如果重装后 SSH 连接失败，先查看 KiwiVM 主页显示的 SSH port，使用新的端口和密码，并确认用户名及防火墙设置。不要假定端口仍是 22。

如果连接信息无误但网络仍有问题，还需要单独排查网络线路。重装系统本身不能替代线路故障排查。

07

QUICK ANSWERS

常见问题

重装后原来的数据还在吗？

面板重装和 DD 都会清除磁盘上的原有数据。操作前先完成备份，并确认恢复所需资料可用。

重装会改变 VPS 的 IP 吗？

参考资料说明，重装或 DD 是替换磁盘系统，不会改变 VPS 的 IP。重装后仍应核对面板中的连接信息。

面板里没有想要的系统怎么办？

可以核实 Mount ISO 的可用选项，或在了解风险后使用可信镜像进行 DD。具体选项取决于面板和镜像的可用情况。

SSH 连不上应该先看哪里？

先核对面板显示的 SSH 端口、用户名和密码，再检查防火墙设置及网络连接。
